# ช่องรูป UI

รูปในโฟลเดอร์นี้ถูกวาดด้วยโค้ดจาก `scripts/art/art.js` (สไตล์การ์ตูนน่ารักโทนพาสเทล)
สร้างใหม่ทั้งหมดได้ด้วย `node scripts/art/render.cjs`

รูปที่ได้จาก Gemini (พื้นเขียว) ให้วางใน `scripts/art/source/<key>.jpg` แล้วรัน
`python3 scripts/art/key_green.py` (ตัดพื้นเขียว → `scripts/art/user/`) ตามด้วย `node scripts/art/render.cjs`
รูปของผู้ใช้จะถูกใช้แทนรูปที่วาด และใช้ประกอบในรูปอื่นด้วย (เช่น ทหารในไอคอนเพิ่มทหาร/โลโก้)
ตอนนี้ใช้รูปของผู้ใช้: camp, timeline, troop, pause, settings

จะเปลี่ยนเป็นรูปสำเร็จรูป (พื้นโปร่งใสอยู่แล้ว) ก็แค่วางไฟล์ทับ ชื่อไฟล์ตาม key เช่น `coin.png`, `logo.png`
(รองรับ `.png` `.webp` `.svg` `.jpg` — ภาพปกยุค `era_card_*` ใช้ `.jpg`) แล้ว build ใหม่
ถ้าเปลี่ยนนามสกุลไฟล์ ให้ลบไฟล์เดิมของ key นั้นออกด้วย

รายการ key ทั้งหมด ขนาดแนะนำ และตำแหน่งที่ใช้ อยู่ใน `../art.ts` (ตัวแปร `SLOTS`)
ปุ่ม (`btn_play`, `btn_ghost`) และกรอบหน้าต่าง (`panel`) ใช้แบบ 9-slice: มุมของรูปไม่ถูกยืด
