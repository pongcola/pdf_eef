# ช่องรูป UI

วางไฟล์รูป (`.png` แนะนำพื้นหลังโปร่งใส, หรือ `.webp` / `.svg`) ไว้ในโฟลเดอร์นี้
ตั้งชื่อไฟล์ตาม key ด้านล่าง เช่น `coin.png`, `logo.png`, `era_card_2.png`
แล้ว build ใหม่ เกมจะใช้รูปนั้นแทนของเดิมอัตโนมัติ ไฟล์ไหนไม่มีก็ใช้ของเดิมต่อ

รายการ key ทั้งหมด ขนาดแนะนำ และตำแหน่งที่ใช้ อยู่ใน `../art.ts` (ตัวแปร `SLOTS`)
