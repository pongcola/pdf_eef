# Crowd Ages — ยุคแห่งฝูงชน

เกมวิ่งยิงพาฝูงทหารข้ามยุคแบบ 3D สำหรับ Android **ไม่มีโฆษณา** เล่นออฟไลน์ได้ 100%
และ **Stamina ฟื้น +1 ทุก 5 นาที**

## วิธีเล่น (แนววิ่งยิง)
- **1 รอบ = เล่นจนทหารหมด หรือผ่านยุค** (ใช้ Stamina 1) ทหารหมดได้เงินที่เก็บมาเต็มจำนวน ไปอัปเกรดแล้วลองใหม่
- **1 ยุค = 4 สเตจ ในรอบเดียว**: สเตจ 1–3 วิ่งยิง (สุ่มหุ่นไล่กา แท่นแคปซูล ป้าย ศัตรู กองเงิน — ทุกสเตจมีแท่นแคปซูลอย่างน้อย 1 แท่น และแถวสุดท้ายของสเตจ 3 เป็นแท่นแคปซูลเสมอ ทหารจากแท่นนี้เข้าฝูงตอนเริ่มสเตจ 4) สเตจ 4 ทุ่งหอคอย
- ลากนิ้วซ้าย–ขวาพาฝูง ทหารยิงเอง 1.3 นัด/วินาที วิ่ง 5 หน่วย/วินาที ฝูงสูงสุด **20 ตัว** (ไม่นับฮีโร่ เกินแล้วไม่มีผล)
- ทหารตายได้แค่ 2 ทาง: **ชนหอคอย** และ **โดนอาวุธที่ศัตรูปา**
- **ป้ายสถานะ**: สุ่มเป็นอัตรายิงหรือระยะยิง และสุ่มว่ามีแผงไม้ปิดหรือไม่ ยิงค่าให้ขึ้นได้ไม่จำกัด ค่าจริง = ค่าบนป้าย × 0.1 (%) เช่น +50 → +5% แล้ววิ่งผ่าน
- **แท่นแคปซูล**: ยิงแคปซูล/แท่นสะสม EXP เต็มแล้วทหารในแคปซูล **Level +1** (สูงสุด 10, ต้องตีมากขึ้น ×1.6 ต่อ Level)
  ยิงแล้วแคปซูลไม่แตก **ต้องเดินชนถึงจะแตก** ชนใบเดียว **แคปซูลทุกใบบนแท่นแตกพร้อมกัน** ทหารทั้งหมดจะวิ่งไป **ยืนรอหลังเส้นแบ่งสเตจถัดไป** พอฝูงวิ่งถึงเส้นก็ได้ทหารเข้าฝูง (สเตจ 3 → รอที่เส้นชัยก่อนทุ่งหอคอย)
- **หุ่นไล่กา (ยิงไม่แตก, แถวละ 1 ตัว, หน้าตาเดียวกันทุกยุค)**: ยิงโดนแต่ละครั้งเติม **เกจด้านซ้าย** เต็มแล้ว **ทุกแท่นที่ยังไม่ผ่านได้แคปซูล +1** (สูงสุด 5)
  จำนวนแคปซูลและเกจอยู่ตลอดรอบ ไม่รีเซ็ตตอนขึ้นสเตจ เกจรอบถัดไปเต็มยากขึ้น (20 ครั้ง ×1.35)
  เดินชนหุ่นไล่กา ทหารไม่ตาย แต่หุ่นหายไป
- **ศัตรูชุดดำ** ยืนปาอาวุธใส่ โดนแล้วทหารตาย 1 ตัว (วิ่งชนแล้วศัตรูล้ม ทหารเราไม่ตาย)
- **กองเงิน** บนถนน ต้องเดินเก็บ
- **ทุ่งหอคอย** (สเตจ 4): 10 แถว แถวละ 3 หอ เลือดเพิ่มตามระยะทาง ชนแล้วฝูงหยุด ทหารตายทีละตัว
  **ไปถึงแถวสุดท้ายได้ = ผ่านยุค** ไม่ต้องยิงทุกหอ เลือกเลนที่เลือดน้อยได้ ไม่จำกัดเวลา
- ความยากเพิ่มทุกสเตจ และหอคอยแข็งขึ้นทุกยุค (×1.4) ไม่มีบอสแล้ว ไม่มีกรง ไม่มีกับดัก
- ทหาร Lv.10 เสื้อสีรุ้ง • ศัตรูแต่ละยุคปาของต่างกัน (กระดูก, โถดินเผา, ลูกตุ้ม, ระเบิด, ระเบิดมือ, ลูกพลาสมา)
- หลังรอบที่ไม่ผ่าน มีโอกาส 40% ได้ **วงล้อโชค** หมุนฟรีคูณเงิน ×1.2–×3 (ไม่ต้องดูโฆษณา)

## ยุคและไทม์ไลน์
- ผ่านยุคแล้ว: ได้ ⚡ +5 (เกินหลอดได้) ⭐ +10 🏆 +3 เหรียญที่เหลือแลกเป็นดาว (400 เหรียญ = 1 ดาว)
  แล้ว **ขึ้นยุคใหม่**: อัปเกรดกลับเป็น Lv.1 และทหารเริ่มใหม่ 1 คน
- 6 ยุค = 1 ไทม์ไลน์: ยุคหิน → โบราณ → อัศวิน → ดินปืน → สมัยใหม่ → อนาคต แล้วเริ่มไทม์ไลน์ถัดไปที่ยากขึ้น

## ฮีโร่ (ปุ่ม "ฮีโร่" ในเมนู)
ฮีโร่ 1 ตัววิ่งตามหลังฝูงและใช้สกิลเองอัตโนมัติ ปลดล็อกเพิ่มทุกยุค อัปเกรดด้วยถ้วยรางวัล 🏆
(ผ่านยุคได้ 3 ถ้วย) Level ฮีโร่รีเซ็ตเป็น 1 เมื่อขึ้นยุคใหม่

| ฮีโร่ | สกิล | ปลดล็อก |
|---|---|---|
| นักปรุงยาเพี้ยน | ปาขวดกรด ระเบิดวงกว้าง + กัดกร่อนต่อเนื่อง | เริ่มเกม |
| นักชกเพลิง | หมัดไฟ มีโอกาสคริติคอล ×3 | ยุค 2 |
| คนตัดไม้ยักษ์ | ขว้างขวานทะลุ 3 เป้า + เลือดไหล | ยุค 3 |
| นักพรตสายลม | โจมตีแล้วปล่อยกระแสลม 3 สาย | ยุค 4 |
| นักบินโดรน | มิสไซล์ถล่มเป้าที่เลือดเยอะสุด ระเบิดวงกว้าง | ยุค 5 |
| นักล่าสมบัติ | ปืนคู่ยิงเร็ว ยิงโดนมีโอกาสได้เงินหรือดาว | ยุค 6 |

แท็บ "สัตว์เลี้ยง" ยังเป็นเร็วๆ นี้

## อุปกรณ์ (แท็บ "อุปกรณ์" ในหน้าทีม) — ของถาวร ไม่รีเซ็ตตอนขึ้นยุค
- **ของดรอป**: ผ่านแต่ละสเตจ (1–4) ได้ Pickaxe 70%, Bomb 20%, **Token** (เหรียญสีเขียว) 20–30 ต่อสเตจ 1–3 และ 150 เมื่อผ่านทุ่งหอคอย ได้ทันที แพ้ทีหลังก็ไม่หาย
- **เหมือง**: Pickaxe 1 อัน 80% ได้หินตีบวก 1–3 ก้อน • Bomb 1 ลูก 50% ได้รูน 1 ชิ้น
- **สุ่มอุปกรณ์**: 100 Token/ครั้ง หรือ 900/10 ครั้ง (การันตี Gold ขึ้นไป) • Silver 60% / Gold 30% / Platinum 8.5% / Legendary 1.5% (การันตี Legendary ครั้งที่ 80)
- **6 ช่อง**: หมวก ชุด รองเท้า เกราะ ถุงมือ อาวุธ (ไอคอนอาวุธเปลี่ยนตามยุค) ช่องละ 2 stat จาก 5 ตัว: โอกาสคริ (ฐาน 5%), ดาเมจคริ (ฐาน 150%), ดาเมจ, อัตรายิง, ระยะยิง
- **ตีบวก +1~+6** ใช้หิน 3 ก้อน โอกาส 80/70/50/40/20/10% • +5, +6 พลาดแล้วลด 1 ระดับ แต่สะสม Pity (+10%/+5% ต่อครั้งที่พลาด) จนการันตี
- **รูน** ชิ้นละ 1 ช่อง (B/A/S/SR) ถอดแล้วคืนกระเป๋า • **แยกชิ้น** อุปกรณ์ที่ไม่ใส่ได้ Token 5/15/50/200
- ค่าจากอุปกรณ์คูณต่อจากป้ายสถานะ ฮีโร่ไม่ได้รับ stat จากอุปกรณ์ • ทหารยิงคริได้ (กระสุนลูกใหญ่)

## อัปเกรด
- **ประจำยุค (ใช้เหรียญ, รีเซ็ตทุกยุค, กดปุ่ม i ดูคำอธิบาย):**
  - รายได้: เพิ่มเงินจากหอคอย สิ่งกีดขวาง และกองเงิน
  - ความจุ: แคปซูลเริ่มต้นบนแท่น (ทุก 10 ระดับ +1 ช่อง แถบบนการ์ด = เกจซ้ายตอนเริ่ม)
  - เพิ่มทหาร: ทหารตอนเริ่มด่าน
  - พลังโจมตี: ดาเมจทหาร
- **ค่ายฝึก (ใช้ดาว, ถาวร):** ทุนตั้งต้น, ฝึกยิง (+ดาเมจ), ทหารผ่านศึก (+ทหารเริ่มต้น), คลังเสบียง (เกจซ้ายเริ่ม +10%)
- ถ้าแพ้ติดกัน ด่านนั้นจะอ่อนลงเล็กน้อย (สูงสุด 3 ครั้ง)

## ติดตั้งบน Android
1. ดาวน์โหลดไฟล์ `CrowdAges-3.6.0.apk` ลงมือถือ
2. เปิดไฟล์ ถ้ามือถือถาม ให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" สำหรับแอปที่ใช้เปิดไฟล์ (เช่น Chrome หรือ Files)
3. กดติดตั้ง แล้วเปิดเกม **Crowd Ages**

รองรับ Android 7.0 ขึ้นไป แอปถูกเซ็นด้วยคีย์เดียวกันทุกครั้ง จึงติดตั้งเวอร์ชันใหม่ทับได้เลย เซฟไม่หาย

## ปรับค่าเกม
ค่าหลักทั้งหมดอยู่ใน [`src/config.ts`](src/config.ts):

```ts
export const STAMINA_MAX = 10;                 // stamina สูงสุด
export const STAMINA_RUN_COST = 1;             // ใช้ต่อ 1 ด่าน
export const STAMINA_REGEN_MS = 5 * 60 * 1000; // +1 ทุก 5 นาที
export const WHEEL_CHANCE = 0.4;               // โอกาสได้วงล้อโชคหลังชนะ
```

stamina คำนวณจากเวลาจริงที่บันทึกไว้ ปิดแอปไปแล้วก็ยังฟื้นตามปกติ

## Build เอง
ต้องมี Node.js 22+, JDK 21 และ Android SDK (ตั้งค่า `ANDROID_HOME`)

```bash
cd game
npm install
npm run dev            # เล่นในเบราว์เซอร์ (เปิดบนมือถือในวง Wi-Fi เดียวกันได้)
npm run android:apk    # ได้ไฟล์ android/app/build/outputs/apk/release/app-release.apk
python3 scripts/make-icons.py  # สร้างไอคอน/หน้า splash ใหม่
```

หรือให้ GitHub build ให้: ทุกครั้งที่ push การเปลี่ยนแปลงในโฟลเดอร์ `game/`
workflow **Crowd Ages APK** จะสร้างไฟล์ APK ไว้ในหน้า Actions (หัวข้อ Artifacts)

> คีย์ `android/app/crowdages-sideload.keystore` ใช้สำหรับติดตั้งเองเท่านั้น (รหัสผ่านอยู่ใน build.gradle)
> ถ้าจะลง Google Play ให้สร้างคีย์ใหม่และเก็บเป็นความลับ

## โครงสร้าง
```
src/
  config.ts        ค่าตั้งหลัก (stamina, ความเร็ว, ขนาดถนน)
  stamina.ts       ระบบ stamina +1 ทุก 5 นาที
  economy.ts       อัปเกรด ราคา รางวัล
  eras.ts          สีและธีมของแต่ละยุค
  save.ts          บันทึกเกมในเครื่อง
  audio.ts         เสียงและเพลง (สังเคราะห์สด ไม่ใช้ไฟล์เสียง)
  game/level.ts    สร้างด่านอัตโนมัติ + ปรับสมดุล
  game/squad.ts    การจัดรูปฝูงทหาร (ระดับทหาร 1–5)
  ui/art.ts        ช่องรูป UI (วางรูปใน ui/art/ เพื่อเปลี่ยนหน้าตา)
  game/game.ts     ลูปเกมหลัก (ยิง, ชน, บอส, ทุ่งคริสตัล)
  render/          โมเดล 3D (ตัวละคร, อาวุธ, เป้า, กับดัก, บอส, ฉาก)
  ui/              หน้าจอเมนู/HUD/ผลลัพธ์
android/           โปรเจกต์ Android (Capacitor)
```

ภาพ เสียง และโมเดลทั้งหมดในเกมสร้างด้วยโค้ดของโปรเจกต์นี้เอง ไม่มีไฟล์จากเกมอื่น
