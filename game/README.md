# Crowd Ages — ยุคแห่งฝูงชน

เกมวิ่งยิงพาฝูงทหารข้ามยุคแบบ 3D สำหรับ Android **ไม่มีโฆษณา** เล่นออฟไลน์ได้ 100%
และ **Stamina ฟื้น +1 ทุก 5 นาที**

## วิธีเล่น (แนววิ่งยิง)
- ลากนิ้วซ้าย–ขวาพาฝูง ทหารยิงอาวุธไปข้างหน้าเอง (อาวุธเปลี่ยนตามยุค: หิน → หอก → ขวาน → ลูกปืนคาบศิลา → กระสุน → เลเซอร์)
- **สิ่งกีดขวาง** มีเลือด ยิงให้แตกก่อนชน (ชนแล้วทหารตาย) แตกแล้วได้เหรียญ ถ้ายิงไม่ทันให้หลบไปเลนอื่น
- **ป้ายค่าพลัง** (อัตรายิง / ระยะยิง / พลังยิง) เริ่มเป็นค่าติดลบ ยิงใส่ให้ค่าเพิ่มจนเป็นสีเขียว แล้ววิ่งผ่านเพื่อรับ
- **กรงเชลย** ยิงแตกแล้วได้ทหารเพิ่ม
- **แท่นทหารพิเศษ** ยิงแคปซูลให้แตก แล้ววิ่งผ่านแท่นเพื่อรับทหารสีทอง (แรงกว่าปกติ 2.5 เท่า)
- ทหารศัตรูสีแดงวิ่งเข้ามาชน ยิงให้ล้มก่อนถึงตัว
- ท้ายด่านเป็น **ทุ่งคริสตัล** ยิงเก็บเหรียญให้ลึกที่สุด ทะลุถึงประตูปราสาทได้โบนัส
- ทุก 5 ด่านเป็น **ราชันแห่งยุค** 👑 ชนะแล้ววิวัฒนาการไปยุคถัดไป
- เคลียร์ครบ 6 ยุค (30 ด่าน) จะเริ่ม **รอบใหม่** ที่ยากขึ้น และทหารเริ่มต้นกลับเหลือ 1 คน (อัปเกรดอื่นยังอยู่)
- หลังชนะมีโอกาส 40% ได้ **วงล้อโชค** หมุนฟรีคูณรางวัล ×1.2–×3 (ไม่ต้องดูโฆษณา)

| ยุค | ด่านในรอบ |
|---|---|
| 🪨 ยุคหิน | 1–5 |
| 🏛️ ยุคโบราณ | 6–10 |
| 🛡️ ยุคอัศวิน | 11–15 |
| 💥 ยุคดินปืน | 16–20 |
| 🚁 ยุคสมัยใหม่ | 21–25 |
| 🚀 ยุคอนาคต | 26–30 |

อัปเกรด 4 แบบ: **เพิ่มทหาร** (ทหารตอนเริ่ม), **ความจุ** (ทหารสูงสุดในฝูง), **พลังโจมตี**, **รายได้**
ถ้าแพ้ติดกัน ด่านนั้นจะอ่อนลงเล็กน้อย (สูงสุด 3 ครั้ง)

## ติดตั้งบน Android
1. ดาวน์โหลดไฟล์ `CrowdAges-2.0.0.apk` ลงมือถือ
2. เปิดไฟล์ ถ้ามือถือถาม ให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" สำหรับแอปที่ใช้เปิดไฟล์ (เช่น Chrome หรือ Files)
3. กดติดตั้ง แล้วเปิดเกม **Crowd Ages**

รองรับ Android 7.0 ขึ้นไป แอปถูกเซ็นด้วยคีย์เดียวกันทุกครั้ง จึงติดตั้งเวอร์ชันใหม่ทับได้เลย เซฟไม่หาย

## ปรับค่าเกม
ค่าหลักทั้งหมดอยู่ใน [`src/config.ts`](src/config.ts):

```ts
export const STAMINA_MAX = 10;                 // stamina สูงสุด
export const STAMINA_RUN_COST = 1;             // ใช้ต่อ 1 ด่าน
export const STAMINA_REGEN_MS = 5 * 60 * 1000; // +1 ทุก 5 นาที
export const WHEEL_CHANCE = 0.4;               // โอกาสได้วงล้อโชคหลังชนะ
```

stamina คำนวณจากเวลาจริงที่บันทึกไว้ ปิดแอปไปแล้วก็ยังฟื้นตามปกติ

## Build เอง
ต้องมี Node.js 22+, JDK 21 และ Android SDK (ตั้งค่า `ANDROID_HOME`)

```bash
cd game
npm install
npm run dev            # เล่นในเบราว์เซอร์ (เปิดบนมือถือในวง Wi-Fi เดียวกันได้)
npm run android:apk    # ได้ไฟล์ android/app/build/outputs/apk/release/app-release.apk
python3 scripts/make-icons.py  # สร้างไอคอน/หน้า splash ใหม่
```

หรือให้ GitHub build ให้: ทุกครั้งที่ push การเปลี่ยนแปลงในโฟลเดอร์ `game/`
workflow **Crowd Ages APK** จะสร้างไฟล์ APK ไว้ในหน้า Actions (หัวข้อ Artifacts)

> คีย์ `android/app/crowdages-sideload.keystore` ใช้สำหรับติดตั้งเองเท่านั้น (รหัสผ่านอยู่ใน build.gradle)
> ถ้าจะลง Google Play ให้สร้างคีย์ใหม่และเก็บเป็นความลับ

## โครงสร้าง
```
src/
  config.ts        ค่าตั้งหลัก (stamina, ความเร็ว, ขนาดถนน)
  stamina.ts       ระบบ stamina +1 ทุก 5 นาที
  economy.ts       อัปเกรด ราคา รางวัล
  eras.ts          สีและธีมของแต่ละยุค
  save.ts          บันทึกเกมในเครื่อง
  audio.ts         เสียงและเพลง (สังเคราะห์สด ไม่ใช้ไฟล์เสียง)
  game/level.ts    สร้างด่านอัตโนมัติ + ปรับสมดุล
  game/squad.ts    การจัดรูปฝูงทหาร
  game/game.ts     ลูปเกมหลัก (ยิง, ชน, บอส, ทุ่งคริสตัล)
  render/          โมเดล 3D (ตัวละคร, อาวุธ, เป้า, กับดัก, บอส, ฉาก)
  ui/              หน้าจอเมนู/HUD/ผลลัพธ์
android/           โปรเจกต์ Android (Capacitor)
```

ภาพ เสียง และโมเดลทั้งหมดในเกมสร้างด้วยโค้ดของโปรเจกต์นี้เอง ไม่มีไฟล์จากเกมอื่น
