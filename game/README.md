# Crowd Ages — ยุคแห่งฝูงชน

เกมวิ่งยิงพาฝูงทหารข้ามยุคแบบ 3D สำหรับ Android **ไม่มีโฆษณา** เล่นออฟไลน์ได้ 100%
และ **Stamina ฟื้น +1 ทุก 5 นาที**

## วิธีเล่น (แนววิ่งยิง)
- ลากนิ้วซ้าย–ขวาพาฝูง ทหารยิงอาวุธไปข้างหน้าเอง (อาวุธเปลี่ยนตามยุค)
- **ป้ายค่าพลัง** (อัตรายิง / ระยะยิง / พลังยิง) มีแผงไม้กั้นอยู่ข้างหน้า ยิงให้แผงพังก่อน
  แล้วยิงป้ายต่อ ค่าจะเพิ่มตามดาเมจ (เช่น -18 → 200) วิ่งผ่านเพื่อรับค่า
- **แท่นแคปซูล**: ยิงแท่นจนแถบเต็ม ทหารในแคปซูล **Level +1** (สูงสุด 10 — ทหาร Level สูงหน้าตาเป็นทหารยุคถัดไปที่แรงกว่า)
  ยิงแคปซูลให้แตก ทหารจะวิ่งไปรอที่ **Collect Area** สีฟ้าข้างหน้า ต้องวิ่งผ่านแถบนั้นถึงจะได้ทหาร
- **ก้อนหิน (ยิงไม่แตก)**: ยิงโดนแต่ละครั้งเติม **เกจด้านซ้าย** เต็มแล้ว **แท่นแคปซูลถัดไปได้แคปซูล +1** (สูงสุด 5)
  เกจรอบถัดไปเต็มยากขึ้น (15 ครั้ง ×1.35) ผ่านแท่นไปแล้ว แท่นถัดไปกลับมาเป็นจำนวนตั้งต้น (1 แคปซูล) และเกจเริ่มใหม่
  เดินชนก้อนหิน ทหารไม่ตาย แต่ก้อนหินหายไป (ชนหอคอยในทุ่งหอคอยยังตาย)
- **แคปซูล**: ยิงแคปซูล/แท่นสะสม EXP (แถบเหนือแท่น) เต็มแล้วทหารในแคปซูล Level +1 (สูงสุด Lv.10)
- **ทหาร**: โมเดลใหม่แบบตัวการ์ตูนหัวโต มีหน้าตา เข็มขัด มือ-รองเท้า ลงเงาแบบ toon
- **กรง**: ยิงแล้วเงินหล่นออกมาทีละกอง แตกแล้วได้ทหาร
- **กองเงิน** บนถนน วิ่งผ่านเพื่อเก็บ
- กับดัก: แผ่นไฟ, ใบเลื่อย, ค้อนแกว่ง, คานหมุน
- **ศัตรูชุดดำ** ยืนเฝ้าแล้ว **ปาอาวุธใส่** โดนแล้วทหารตาย 1 ตัว ยิงให้ล้มก่อน (ล้มแล้วอาจทิ้งเงิน)
- ท้ายด่านเป็น **ทุ่งหอคอย** (ฟ้า → เขียว → ม่วง → ทอง) มีเงินบนยอด บางหอมีดาว **ไม่จำกัดเวลา**
  ชนหอคอยแล้วฝูงหยุด **ทหารตายทีละตัว** จนกว่าจะยิงหอคอยแตก (การชนไม่ทำให้เลือดหอคอยลด)
  ทหารหมดก็ยังนับว่าผ่านด่าน ทะลุถึงประตูปราสาทได้โบนัส
- **ความยากเพิ่มขึ้นทุกด่าน** ต่อเนื่องไม่รีเซ็ตตอนขึ้นยุคใหม่ (อัปเกรดรีเซ็ต แต่ด่านไม่ง่ายลง)
- หลังชนะมีโอกาส 40% ได้ **วงล้อโชค** หมุนฟรีคูณรางวัล ×1.2–×3 (ไม่ต้องดูโฆษณา)

## ยุคและไทม์ไลน์
- 1 ยุค = 5 ด่าน ด่านที่ 5 สู้ **ราชันแห่งยุค** 👑
- เคลียร์ยุคแล้ว: ได้ ⚡ +5 (เกินหลอดได้) และ ⭐ +10, เหรียญที่เหลือแลกเป็นดาว (400 เหรียญ = 1 ดาว)
  แล้ว **ขึ้นยุคใหม่**: อัปเกรดกลับเป็น Lv.1 และทหารเริ่มใหม่ 1 คน
- 6 ยุค = 1 ไทม์ไลน์ ครบแล้วเริ่มไทม์ไลน์ถัดไปที่ยากขึ้น ดูความคืบหน้าได้ที่ปุ่ม **ไทม์ไลน์** ในเมนู

| ยุค | ด่าน (ไทม์ไลน์ 1) |
|---|---|
| 🪨 ยุคหิน | 1–5 |
| 🏛️ ยุคโบราณ | 6–10 |
| 🛡️ ยุคอัศวิน | 11–15 |
| 💥 ยุคดินปืน | 16–20 |
| 🚁 ยุคสมัยใหม่ | 21–25 |
| 🚀 ยุคอนาคต | 26–30 |

## ฮีโร่ (ปุ่ม "ฮีโร่" ในเมนู)
ฮีโร่ 1 ตัววิ่งตามหลังฝูงและใช้สกิลเองอัตโนมัติ ปลดล็อกเพิ่มทุกยุค อัปเกรดด้วยถ้วยรางวัล 🏆
(ชนะด่านได้ 1 ถ้วย ชนะบอสยุคได้ 3 ถ้วย) Level ฮีโร่รีเซ็ตเป็น 1 เมื่อขึ้นยุคใหม่

| ฮีโร่ | สกิล | ปลดล็อก |
|---|---|---|
| นักปรุงยาเพี้ยน | ปาขวดกรด ระเบิดวงกว้าง + กัดกร่อนต่อเนื่อง | เริ่มเกม |
| นักชกเพลิง | หมัดไฟ มีโอกาสคริติคอล ×3 | ยุค 2 |
| คนตัดไม้ยักษ์ | ขว้างขวานทะลุ 3 เป้า + เลือดไหล | ยุค 3 |
| นักพรตสายลม | โจมตีแล้วปล่อยกระแสลม 3 สาย | ยุค 4 |
| นักบินโดรน | มิสไซล์ถล่มเป้าที่เลือดเยอะสุด ระเบิดวงกว้าง | ยุค 5 |
| นักล่าสมบัติ | ปืนคู่ยิงเร็ว ยิงโดนมีโอกาสได้เงินหรือดาว | ยุค 6 |

แท็บ "สัตว์เลี้ยง" และ "อุปกรณ์" ยังเป็นเร็วๆ นี้

## อัปเกรด
- **ประจำยุค (ใช้เหรียญ, รีเซ็ตทุกยุค, กดปุ่ม i ดูคำอธิบาย):**
  - รายได้: เพิ่มเงินจากหอคอย สิ่งกีดขวาง และกองเงิน
  - ความจุ: แคปซูลเริ่มต้นบนแท่น (ทุก 10 ระดับ +1 ช่อง แถบบนการ์ด = เกจซ้ายตอนเริ่ม)
  - เพิ่มทหาร: ทหารตอนเริ่มด่าน
  - พลังโจมตี: ดาเมจทหาร
- **ค่ายฝึก (ใช้ดาว, ถาวร):** ทุนตั้งต้น, ฝึกยิง (+ดาเมจ), ทหารผ่านศึก (+ทหารเริ่มต้น), คลังเสบียง (เกจซ้ายเริ่ม +10%)
- ถ้าแพ้ติดกัน ด่านนั้นจะอ่อนลงเล็กน้อย (สูงสุด 3 ครั้ง)

## เปลี่ยนรูป UI
วางไฟล์ PNG ชื่อตามช่องรูปไว้ใน `src/ui/art/` แล้ว build ใหม่ เกมจะใช้รูปนั้นแทนอีโมจิ/สไตล์เดิมทันที
รายการช่องรูปทั้งหมด ขนาดแนะนำ และตำแหน่งที่ใช้ อยู่ใน `src/ui/art.ts`

## ติดตั้งบน Android
1. ดาวน์โหลดไฟล์ `CrowdAges-3.6.0.apk` ลงมือถือ
2. เปิดไฟล์ ถ้ามือถือถาม ให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" สำหรับแอปที่ใช้เปิดไฟล์ (เช่น Chrome หรือ Files)
3. กดติดตั้ง แล้วเปิดเกม **Crowd Ages**

รองรับ Android 7.0 ขึ้นไป แอปถูกเซ็นด้วยคีย์เดียวกันทุกครั้ง จึงติดตั้งเวอร์ชันใหม่ทับได้เลย เซฟไม่หาย

## ปรับค่าเกม
ค่าหลักทั้งหมดอยู่ใน [`src/config.ts`](src/config.ts):

```ts
export const STAMINA_MAX = 10;                 // stamina สูงสุด
export const STAMINA_RUN_COST = 1;             // ใช้ต่อ 1 ด่าน
export const STAMINA_REGEN_MS = 5 * 60 * 1000; // +1 ทุก 5 นาที
export const WHEEL_CHANCE = 0.4;               // โอกาสได้วงล้อโชคหลังชนะ
```

stamina คำนวณจากเวลาจริงที่บันทึกไว้ ปิดแอปไปแล้วก็ยังฟื้นตามปกติ

## Build เอง
ต้องมี Node.js 22+, JDK 21 และ Android SDK (ตั้งค่า `ANDROID_HOME`)

```bash
cd game
npm install
npm run dev            # เล่นในเบราว์เซอร์ (เปิดบนมือถือในวง Wi-Fi เดียวกันได้)
npm run android:apk    # ได้ไฟล์ android/app/build/outputs/apk/release/app-release.apk
python3 scripts/make-icons.py  # สร้างไอคอน/หน้า splash ใหม่
```

หรือให้ GitHub build ให้: ทุกครั้งที่ push การเปลี่ยนแปลงในโฟลเดอร์ `game/`
workflow **Crowd Ages APK** จะสร้างไฟล์ APK ไว้ในหน้า Actions (หัวข้อ Artifacts)

> คีย์ `android/app/crowdages-sideload.keystore` ใช้สำหรับติดตั้งเองเท่านั้น (รหัสผ่านอยู่ใน build.gradle)
> ถ้าจะลง Google Play ให้สร้างคีย์ใหม่และเก็บเป็นความลับ

## โครงสร้าง
```
src/
  config.ts        ค่าตั้งหลัก (stamina, ความเร็ว, ขนาดถนน)
  stamina.ts       ระบบ stamina +1 ทุก 5 นาที
  economy.ts       อัปเกรด ราคา รางวัล
  eras.ts          สีและธีมของแต่ละยุค
  save.ts          บันทึกเกมในเครื่อง
  audio.ts         เสียงและเพลง (สังเคราะห์สด ไม่ใช้ไฟล์เสียง)
  game/level.ts    สร้างด่านอัตโนมัติ + ปรับสมดุล
  game/squad.ts    การจัดรูปฝูงทหาร (ระดับทหาร 1–5)
  ui/art.ts        ช่องรูป UI (วางรูปใน ui/art/ เพื่อเปลี่ยนหน้าตา)
  game/game.ts     ลูปเกมหลัก (ยิง, ชน, บอส, ทุ่งคริสตัล)
  render/          โมเดล 3D (ตัวละคร, อาวุธ, เป้า, กับดัก, บอส, ฉาก)
  ui/              หน้าจอเมนู/HUD/ผลลัพธ์
android/           โปรเจกต์ Android (Capacitor)
```

ภาพ เสียง และโมเดลทั้งหมดในเกมสร้างด้วยโค้ดของโปรเจกต์นี้เอง ไม่มีไฟล์จากเกมอื่น
