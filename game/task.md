### ระบบอุปกรณ์ (Item) — แท็บ "อุปกรณ์" ในหน้าทีม
แผนเต็ม: [`docs/item-system-plan.md`](docs/item-system-plan.md) • prompt ไอคอน: [`docs/gemini-item-icons-prompt.md`](docs/gemini-item-icons-prompt.md)
สรุป: อุปกรณ์ 6 ช่อง (หมวก ชุด รองเท้า เกราะ ถุงมือ อาวุธ) × 4 class (Silver / Gold / Platinum / Legendary), stat 5 ตัว (Crit Rate, Crit Dmg, Dmg, Attack Rate, Attack Range), ตีบวก +1~+6 มี Pity, รูน 1 ช่อง/ชิ้น (B/A/S/SR), เหมือง (Pickaxe → หิน, Bomb → รูน), สุ่มด้วยเพชร (1/10 ครั้ง, การันตี Legendary ครั้งที่ 80), แยกชิ้นเป็นเพชร — ทุกอย่างถาวร ไม่รีเซ็ตตอนขึ้นยุค

**ต้องยืนยันก่อนเริ่ม**
- [ ] ชื่อสกุลเงิน "เพชร" — ระวังสับสนกับ `crystal` ที่เกมใช้อยู่แล้ว (ไอคอนทุ่งหอคอยในจุดสเตจและแถบความคืบหน้า, คลาส `CrystalTarget` = หอคอย)
- [ ] ไอคอนช่องอาวุธเป็นดาบอันเดียว หรือเปลี่ยนตามยุค
- [ ] ความเร็วหาของ: ตี +6 หนึ่งชิ้นต้องเล่น ~116 รอบ ใช้ตามนี้หรือเพิ่มเรทดรอป

**ลำดับการพัฒนา**
- [ ] 1. `src/gear.ts` (ใหม่): ตัวเลขทั้งหมด + ตีบวก/Pity, รูน, เหมือง, สุ่ม/Pity กาชา, แยกชิ้น, คำนวณ stat รวม (ไม่ผูก 3D/UI) + ทดสอบกติกาทุกข้อ + จำลองความสมดุล
- [ ] 2. `src/save.ts`: เพิ่ม `gear` (diamonds, pickaxes, bombs, stones, gachaPity, items, runes, equipped) + เติมค่าเริ่มต้นให้เซฟเก่า (เพิ่ม save version + migration)
- [ ] 3. `src/game/game.ts`: ใช้ stat ตอนยิง — อัตรายิง × (1+AttackRate%), ระยะ × (1+AttackRange%), ดาเมจ × (1+Dmg%) + **ระบบคริของทหาร** (ฐาน 5% / 150%); คูณต่อจากป้ายสถานะ; ป้ายสถานะหาร Dmg% ออกตอนคิดค่าที่เพิ่ม; ฮีโร่ไม่ได้ stat จากอุปกรณ์
- [ ] 4. ดรอปของตอนผ่านแต่ละสเตจ (Pickaxe 30%, Bomb 10%, เพชร 5–15 สเตจ 1–3 / 50 สเตจ 4) — ได้ทันที แพ้กลางรอบไม่หาย + แสดงในหน้าสรุปผล
- [ ] 5. UI แท็บ "สวมใส่": 6 ช่องรอบรูปทหาร + stat รวม, กระเป๋า (กรองช่อง/class), หน้ารายละเอียด (ใส่/ถอด, ตีบวกแสดงโอกาส+Pity+ระดับถ้าพลาด, ใส่/ถอดรูน, แยกชิ้น), เทียบค่าเขียว/แดง
- [ ] 6. UI แท็บ "เหมือง": จำนวน Pickaxe/Bomb/หิน, ปุ่มขุด/ระเบิด (+ใช้ทั้งหมด), กระเป๋ารูน
- [ ] 7. UI แท็บ "สุ่ม": จำนวนเพชร, สุ่ม 1 (100) / 10 (900, การันตี Gold+), ตัวนับ Pity Legendary, ตาราง rate
- [ ] 8. `src/ui/styles.css` กรอบสีตาม class + `src/ui/art.ts` ช่องรูปไอคอนใหม่ (ใช้อีโมจิก่อน) + `src/main.ts` ผูก handler
- [ ] 9. ใส่ไอคอนจริงจาก Gemini + ปรับตัวเลขหลังลองเล่น
- [ ] 10. อัปเดต README, วิธีเล่น, agent.md, rule.md, เอกสารสเปก, เลขเวอร์ชัน + build APK
