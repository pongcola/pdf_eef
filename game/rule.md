# CrowdAges — กฎ (Rules)

กฎทุกข้อในไฟล์นี้มาจากคำสั่งของเจ้าของโปรเจกต์ ถ้าจะเปลี่ยนข้อไหนต้องได้รับการยืนยันจากเจ้าของก่อน
ภาพรวมระบบดู [`agent.md`](agent.md) • รายการงานดู [`task.md`](task.md)

---

## 1. กฎของผลิตภัณฑ์ (ห้ามละเมิด)
1. **ไม่มีโฆษณา** และไม่มีการซื้อในแอป ทุกรางวัล (รวมวงล้อ) ต้องได้ฟรี
2. **Stamina**: สูงสุด 10, ฟื้น +1 ทุก 5 นาทีตามเวลาจริง (ปิดแอปก็ฟื้น), เล่น 1 รอบใช้ 1, ผ่านยุค +5 (เกินหลอดได้)
3. **ของเราเองทั้งหมด**: ห้ามใช้ชื่อ ตัวละคร รูป เสียง หรือเลเวลของ Mob Era หรือเกมอื่น ห้ามดาวน์โหลด/แกะ APK ของเกมอื่น ใช้ได้แค่ "แนวเกม" เป็นแรงบันดาลใจ
4. ส่งมอบเป็น **APK** ที่ติดตั้งเองได้ (sideload) ข้อความในเกมเป็น **ภาษาไทย**

## 2. กฎเกมเพลย์ (สเปกปัจจุบัน — เปลี่ยนเมื่อเจ้าของสั่งเท่านั้น)

**รอบและยุค**
- 1 รอบ = เล่นจนทหารหมด หรือผ่านยุค
- 1 ยุค = 4 สเตจในรอบเดียว: สเตจ 1–3 วิ่งยิง, สเตจ 4 ทุ่งหอคอย
- ผ่านยุค = ไปถึงหอคอยแถวสุดท้าย ไม่ต้องทำลายทุกหอ
- ไม่มีบอส ไม่มีกรงเชลย ไม่มีกับดัก ไม่มีป้ายพลังยิง

**ทหาร**
- วิ่ง 5 หน่วย/วิ ยิง **1.3 นัด/วินาที** (ดาเมจต่อนัดคงเดิม)
- ฝูงสูงสุด **20** ไม่นับฮีโร่ ได้เกินแล้ว **ไม่มีผลใดๆ**
- ทหารตายได้ **2 ทางเท่านั้น**: ชนหอคอย และโดนอาวุธที่ศัตรูปา

**หุ่นไล่กา** (เดิมคือก้อนหิน)
- หน้าตา **เดียวกันทุกยุค** • **แถวละ 1 ตัว**
- ยิงไม่แตก ทุกนัดที่โดนเติมหลอดซ้าย • ชนแล้วหุ่นหายไป ทหารไม่ตาย

**หลอดซ้าย**
- เต็มแล้ว **ทุกแท่นที่ยังไม่ได้เก็บ** ได้แคปซูล +1 (สูงสุด 5)
- หลอดและโบนัส **ไม่รีเซ็ตตอนขึ้นสเตจ** อยู่ตลอดรอบ

**แท่นแคปซูลทหาร**
- **ทุกสเตจ 1–3 มีอย่างน้อย 1 แท่น** และ **แถวสุดท้ายของสเตจ 3 เป็นแท่นเสมอ**
- ยิงแคปซูล/แท่น = EXP แท่น → **Level = ความแรงของทหาร** (สูงสุด 10)
- แคปซูล **แตกเมื่อเดินชนเท่านั้น** (กระสุนไม่ทำให้แตก)
- ชนใบเดียว **แตกทุกใบบนแท่น** ได้ทหารทั้งหมด
- ทหารที่ได้ **ไปยืนรอหลังเส้นแบ่งสเตจถัดไป** และเข้าฝูงเมื่อฝูงข้ามเส้น

**ป้ายสถานะ**
- สุ่มชนิด อัตรายิง หรือ ระยะยิง • สุ่มมี/ไม่มีแผงไม้กั้น
- ยิงเพิ่มค่าได้ **ไม่จำกัด** • ค่าจริง = ค่าบนป้าย × **0.1%**

**อุปกรณ์**
- อุปกรณ์ รูน หิน Pickaxe Bomb Token เป็นของ **ถาวร** ไม่รีเซ็ตตอนขึ้นยุค
- สกุลเงินสุ่มชื่อ **Token** หน้าตาเป็น **เหรียญสีเขียว** (ไม่ใช้คำว่า "เพชร" — ชนกับคริสตัลของทุ่งหอคอย)
- ไอคอนอาวุธ **เปลี่ยนตามยุค** ที่กำลังเล่น
- เรทดรอปตั้งให้สูงกว่าแผนเดิม ปรับได้ที่ `DROP` ใน `src/gear.ts` เท่านั้น
- ค่าจากอุปกรณ์คูณต่อจากป้ายสถานะ ฮีโร่ไม่ได้รับ stat จากอุปกรณ์
- ตัวเลข/กติกาของระบบอุปกรณ์ต้องอยู่ใน `src/gear.ts` (pure function รับ rng) และต้องผ่านสคริปต์ทดสอบกติกาก่อน commit

**ศัตรู, เงิน, หอคอย**
- ศัตรูชุดดำยืนปาอาวุธ ชนแล้วศัตรูล้ม ทหารเราไม่ตาย
- กองเงิน **ต้องเดินเก็บ** ยิงเก็บไม่ได้
- เลือดหอคอยเพิ่มตามระยะ (แถวลึกขึ้นแข็งขึ้น)

## 3. กฎการพัฒนา
1. แก้เฉพาะในโฟลเดอร์ `game/` ส่วนอื่นของ repo เป็นโปรเจกต์อื่น
2. ตัวเลขที่ปรับบ่อยต้องอยู่ใน `src/config.ts` หรือ `src/economy.ts` ไม่ฝังตัวเลขกระจายในโค้ด
3. คอมเมนต์และข้อความ UI เป็นภาษาไทย ชื่อตัวแปร/ฟังก์ชันเป็นภาษาอังกฤษ
4. `npm run build` (รวม `tsc --noEmit`) ต้องผ่านก่อน commit ทุกครั้ง
5. ทุกการเปลี่ยนกติกา ต้องทดสอบจริงในเบราว์เซอร์ด้วย Playwright (ภาพหน้าจอ หรือบอทที่อ่าน `window.__game`) ไม่ใช่แค่คอมไพล์ผ่าน
6. เปลี่ยนอะไรที่กระทบความยาก ต้องรันบอท `campaign.cjs` ยุค 1, 3, 6, 8 แล้วเทียบกับผลเดิม ปรับให้ใกล้เคียงเดิม (เป้าหมายปัจจุบัน: ยุคแรกผ่านใน 1 รอบ ยุคหลังใช้ 2–4 รอบโดยซื้ออัปเกรดระหว่างรอบ) และรายงานผลให้เจ้าของ
7. การเปลี่ยนอัตรายิงต้องไม่เปลี่ยนดาเมจต่อนัด (`FIRE_RATE_SCALE` ล็อกที่ 1/2.2) — สูตรเลือดใน `level.ts` คูณ `BASE_FIRE_RATE` อยู่แล้ว
8. Save format เปลี่ยนเมื่อไร ต้องเพิ่ม `version` และเขียน migration ใน `src/save.ts` ห้ามทำให้เซฟเก่าหาย

## 4. กฎเวอร์ชันและการส่งมอบ
1. ทุกการส่งงานที่เปลี่ยนเกม: เพิ่ม `version` ใน `package.json` และ `versionName` + `versionCode` ใน `android/app/build.gradle`
2. ทุกเวอร์ชันต้องอัปเดตให้ตรงกัน:
   - `README.md` (คู่มือผู้เล่น)
   - ข้อความ "วิธีเล่น" ในหน้าตั้งค่า (`src/ui/ui.ts`)
   - เอกสารสเปก https://claude.ai/artifact/R8eqYyAAdQs2tbhQw77sbh (ชื่อมีเลขเวอร์ชัน)
   - `agent.md` / `task.md` ในโฟลเดอร์นี้
3. Build APK แล้ว **ห้าม commit ไฟล์ APK** เข้า repo ให้คัดลอกไปไว้นอก repo แล้วส่งให้ผู้ใช้
4. Commit บน branch `claude/mob-era-game-no-ads-u6lur6` เท่านั้น แล้ว push ห้ามสร้าง PR เองถ้าไม่ได้สั่ง
5. ข้อความ commit ห้ามมีชื่อรุ่นโมเดล
6. เมื่อเจ้าของขอ "แผน" ให้ส่งแผนแล้วรอยืนยันก่อนลงมือ เมื่อสั่งทำ ให้ทำจนจบ (โค้ด → ทดสอบ → APK → เอกสาร → push)
