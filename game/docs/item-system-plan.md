# แผนระบบอุปกรณ์ (Item) — Crowd Ages

สรุปทุกอย่างที่ตกลงกันไว้ สำหรับเพิ่มลงในแท็บ **"อุปกรณ์"** ของหน้าทีม (ตอนนี้ยังขึ้นว่า "เร็วๆ นี้")
เกมเล่นคนเดียว ออฟไลน์ ไม่ต้องมี Backend เซฟลงเครื่องผ่าน `localStorage` เหมือนระบบเดิม

---

## 1. ภาพรวม

```
เล่นด่าน (ผ่านแต่ละสเตจ) ──> Pickaxe 30% ──ขุด──> หินตีบวก 50% (ได้ 1–3 ก้อน) ──> ตีบวก +1~+6
                        ├─> Bomb 10%    ──ระเบิด─> รูน 30%                   ──> ใส่รูน (ชิ้นละ 1)
                        └─> เพชร 5–15   ──────────> สุ่มอุปกรณ์ (กาชา)
                                                                                     │
อุปกรณ์ 6 ช่อง × 4 class ──สวมใส่──> Status ของฝูงทหาร <───────────────────────────────┘
```

- ตัวละครไม่โดนโจมตีจนตาย จึงไม่มี HP/DEF มีแต่ stat โจมตี 5 ตัว
- อุปกรณ์ รูน หิน และเพชร **เป็นของถาวร ไม่รีเซ็ตตอนขึ้นยุคใหม่** (ต่างจากอัปเกรดประจำยุค)

## 2. Stat ทั้งหมด (5 ตัว ใช้ร่วมกันทั้งอุปกรณ์และรูน)

| Stat | ผลในเกม |
|---|---|
| Crit Rate | โอกาสที่กระสุนทหารติดคริ (ค่าพื้นฐาน 5%, เพดาน 100%) |
| Crit Dmg | ดาเมจตอนติดคริ (ค่าพื้นฐาน 150%) |
| Dmg | ดาเมจกระสุนทหาร +% |
| Attack Rate | อัตรายิง +% (คูณกับ `BASE_FIRE_RATE` 1.3 นัด/วิ) |
| Attack Range | ระยะยิง +% (คูณกับ `BASE_RANGE` 13, เพดาน +100%) |

ระบบคริของทหารยังไม่มีในเกม ต้องเพิ่มใหม่ (ตอนนี้มีแค่สกิลฮีโร่นักชกเพลิง)

## 3. อุปกรณ์: 6 ช่อง × 4 Class

### Stat ของแต่ละช่อง

| ช่อง | Stat 1 | Stat 2 |
|---|---|---|
| หมวก | Attack Range | Attack Rate |
| ชุด | Attack Rate | Crit Rate |
| รองเท้า | Crit Rate | Attack Range |
| เกราะ | Dmg | Attack Rate |
| ถุงมือ | Crit Rate | Crit Dmg |
| อาวุธ | Dmg | Crit Rate |

### ค่า stat ต่อชิ้นที่ +0

| Stat | Silver | Gold | Platinum | Legendary |
|---|---|---|---|---|
| Crit Rate | 2% | 3% | 4.5% | 6% |
| Crit Dmg | 8% | 12% | 18% | 25% |
| Dmg | 5% | 8% | 12% | 16% |
| Attack Rate | 3% | 4.5% | 6.5% | 9% |
| Attack Range | 4% | 6% | 9% | 12% |

ค่าในเกมใช้ชื่อ class ว่า Silver / Gold / Platinum / Legendary

## 4. ตีบวก (+1 ถึง +6)

- ทุกขั้นใช้ **หิน 3 ก้อน**
- ตีสำเร็จแล้ว stat ของชิ้นนั้นคูณตามตาราง

| ตีไป | โอกาสพื้นฐาน | ถ้าพลาด | Pity ต่อครั้งที่พลาด | ตัวคูณ stat เมื่อถึงขั้นนี้ |
|---|---|---|---|---|
| +1 | 80% | เสียแค่หิน | – | ×1.05 |
| +2 | 70% | เสียแค่หิน | – | ×1.10 |
| +3 | 50% | เสียแค่หิน | – | ×1.18 |
| +4 | 40% | เสียแค่หิน | – | ×1.28 |
| +5 | 20% | **ลดลง 1 ระดับ (เหลือ +3)** | +10% | ×1.40 |
| +6 | 10% | **ลดลง 1 ระดับ (เหลือ +4)** | +5% | ×1.55 |

**กติกา Pity**
- เก็บแยกตามอุปกรณ์แต่ละชิ้น และแยกตามขั้น (+5 กับ +6 นับแยกกัน)
- สะสมไปเรื่อย ๆ จนถึง 100% (+5 การันตีหลังพลาด 8 ครั้ง, +6 การันตีหลังพลาด 18 ครั้ง)
- **ตกระดับแล้ว Pity ไม่หาย** รีเซ็ตเป็น 0 เฉพาะตอนตีขั้นนั้นสำเร็จ
- หน้าจอตีบวกต้องแสดงให้ผู้เล่นเห็น เช่น
  `โอกาสสำเร็จ: 25% (พื้นฐาน 10% + Pity 15%)  ⚠️ ถ้าพลาด จะลดเป็น +4`

## 5. รูน (พลังแฝง)

- อุปกรณ์ **1 ชิ้นใส่รูนได้ 1 ช่อง** ทุก class (ใส่ครบชุดได้สูงสุด 6 รูน)
- ถอดรูนแล้ว **รูนคืนเข้ากระเป๋า** ไม่เสียอะไร
- ใส่รูนใหม่ทับ รูนเก่าคืนกระเป๋าอัตโนมัติ
- ได้รูนแล้วสุ่ม stat 1 ใน 5 อย่างด้วยโอกาสเท่ากัน และสุ่ม tier ตามตาราง

| Stat | B | A | S | SR |
|---|---|---|---|---|
| Crit Rate | +2% | +4% | +7% | +12% |
| Crit Dmg | +5% | +10% | +18% | +30% |
| Dmg | +3% | +6% | +10% | +16% |
| Attack Rate | +3% | +5% | +9% | +15% |
| Attack Range | +5% | +8% | +12% | +20% |
| **โอกาสได้ tier** | 60% | 28% | 10% | 2% |

## 6. ของดรอปและเหมือง

| ได้จาก | ของ | โอกาส / จำนวน |
|---|---|---|
| ผ่านแต่ละสเตจ (สเตจ 1–4) | Pickaxe | 30% |
| ผ่านแต่ละสเตจ | Bomb | 10% |
| ผ่านสเตจ 1–3 | เพชร | 5–15 |
| ผ่านทุ่งหอคอย (สเตจ 4) | เพชร | 50 |
| ใช้ Pickaxe 1 อัน | หินตีบวก | 50% ได้ 1–3 ก้อน |
| ใช้ Bomb 1 ลูก | รูน | 30% ได้ 1 ชิ้น |

- ได้ของทันทีที่ผ่านสเตจ ถ้าแพ้กลางรอบ ของจากสเตจที่ผ่านไปแล้วยังอยู่
- หน้าสรุปผลจบรอบแสดงของที่ได้ในรอบนั้น

## 7. สุ่มอุปกรณ์ (ใช้เพชร)

| แบบ | ราคา | การันตี |
|---|---|---|
| สุ่ม 1 ครั้ง | 100 เพชร | – |
| สุ่ม 10 ครั้ง | 900 เพชร | ได้ Gold ขึ้นไปอย่างน้อย 1 ชิ้น |

| Class | Rate |
|---|---|
| Silver | 60% |
| Gold | 30% |
| Platinum | 8.5% |
| Legendary | 1.5% (สุ่มครบ 80 ครั้งยังไม่ได้ → ครั้งที่ 80 การันตี) |

- ช่องอุปกรณ์สุ่มเท่ากันทั้ง 6 ช่อง (1/6)
- **แยกชิ้น** อุปกรณ์ที่ไม่ใช้เป็นเพชร: Silver 5 / Gold 15 / Platinum 50 / Legendary 200
  ห้ามแยกชิ้นที่ใส่อยู่ ถ้ามีรูนติดอยู่ รูนคืนกระเป๋า

## 8. สูตรคำนวณ

```
item_stat   = ค่าต่อชิ้น[stat][class] × ตัวคูณตีบวก[ระดับ]
total[stat] = ค่าพื้นฐาน + Σ item_stat (6 ช่อง) + Σ ค่ารูน (สูงสุด 6 ชิ้น)
total[stat] = min(total, เพดาน)      // Crit Rate ≤ 100%, Attack Range ≤ +100%

อัตรายิง  = BASE_FIRE_RATE × rateMul(ป้ายสถานะ) × (1 + AttackRate%)
ระยะยิง   = BASE_RANGE    × rangeMul(ป้ายสถานะ) × (1 + AttackRange%)
ดาเมจนัด  = ดาเมจเดิม × (1 + Dmg%) × (ติดคริ ? CritDmg% : 1)
```

- ค่าจากอุปกรณ์คูณ **ต่อจาก** ป้ายสถานะระหว่างวิ่ง (ไม่แทนที่ระบบเดิม)
- ป้ายสถานะ: ตอนคำนวณค่าที่เพิ่มเมื่อยิงป้าย ให้หาร Dmg% จากอุปกรณ์ออก ป้ายจะไม่ขึ้นเร็วเกินไป
- ฮีโร่ไม่ได้รับ stat จากอุปกรณ์ (อุปกรณ์เป็นของฝูงทหาร)

### ค่าสูงสุด (Legendary +6 ครบชุด + รูน SR stat เดียวกัน 6 ชิ้น)

| Stat | จากอุปกรณ์ | จากรูน | รวม |
|---|---|---|---|
| Crit Rate | 37.2% | 72% | ติดเพดาน 100% |
| Crit Dmg | 38.75% | 180% | 150 + 218.75% |
| Dmg | 49.6% | 96% | +145.6% |
| Attack Rate | 41.85% | 90% | +131.85% |
| Attack Range | 37.2% | 120% | ติดเพดาน +100% |

## 9. ความสมดุล (จากการจำลองจริง)

| เป้าหมาย | ประมาณ |
|---|---|
| ตี +0 ถึง +6 หนึ่งชิ้น | ~139 หิน หรือ ~465 สเตจ |
| Legendary 1 ชิ้นจากการสุ่ม | ~46 ครั้ง |
| รูน 1 ชิ้น | ~33 สเตจ |
| รูน SR 1 ชิ้น | ~1,400 สเตจ |

⚠️ 1 รอบเล่นได้สูงสุด 4 สเตจ และใช้ Stamina 1 (ฟื้น +1 ทุก 5 นาที)
ตี +6 หนึ่งชิ้นจึงต้องเล่นประมาณ **116 รอบขึ้นไป** ถ้าช้าเกินไปให้ปรับตัวเลขในไฟล์ config ของระบบนี้

## 10. ข้อมูลที่เพิ่มในเซฟ (`src/save.ts`)

```ts
gear: {
  diamonds: number;
  pickaxes: number;
  bombs: number;
  stones: number;
  gachaPity: number;                     // จำนวนครั้งตั้งแต่ได้ Legendary ล่าสุด
  items: {
    id: string; slot: Slot; cls: Cls;
    plus: number;                        // 0–6
    pity: number[];                      // จำนวนครั้งที่พลาด แยกตามขั้น [6]
    rune: string;                        // id รูนที่ใส่ ('' = ไม่มี)
  }[];
  runes: { id: string; stat: Stat; tier: Tier; on: string }[];  // on = id อุปกรณ์ ('' = อยู่ในกระเป๋า)
  equipped: string[];                    // 6 ช่อง ตามลำดับ หมวก ชุด รองเท้า เกราะ ถุงมือ อาวุธ
}
```

`loadSave` ต้องเติมค่าเริ่มต้นให้เซฟเก่าที่ยังไม่มี `gear` ผู้เล่นเดิมเซฟไม่หาย

## 11. ไฟล์ที่ต้องเพิ่ม/แก้

| ไฟล์ | งาน |
|---|---|
| `src/gear.ts` (ใหม่) | ตัวเลขทั้งหมด + ระบบตีบวก รูน เหมือง สุ่ม แยกชิ้น คำนวณ stat (ไม่ผูกกับ 3D/UI) |
| `src/save.ts` | เพิ่ม `gear` + ย้ายข้อมูลจากเซฟเก่า |
| `src/game/game.ts` | ใช้ stat ตอนยิง (อัตรายิง ระยะ ดาเมจ คริ), ดรอปของตอนผ่านสเตจ, ส่งของที่ได้ไปหน้าสรุปผล |
| `src/ui/ui.ts` | แท็บ "อุปกรณ์" ในหน้าทีม (ปลดล็อก) |
| `src/ui/styles.css` | สไตล์ช่องอุปกรณ์ กรอบสีตาม class หน้าตีบวก/เหมือง/สุ่ม |
| `src/ui/art.ts` | เพิ่มช่องรูปไอคอนใหม่ (ใช้อีโมจิไปก่อนจนกว่าจะมีรูป) |
| `src/main.ts` | ผูก handler ใหม่ของ UI กับ Game |

## 12. หน้าจอ (แท็บ "อุปกรณ์")

แบ่งเป็น 3 แท็บย่อย

1. **สวมใส่**
   - 6 ช่องรอบรูปทหาร + สรุป stat รวม 5 ตัว
   - กระเป๋าด้านล่าง กรองตามช่อง/class ได้
   - กดอุปกรณ์แล้วเปิดรายละเอียด: stat, ระดับ +, รูน
   - ปุ่มในหน้ารายละเอียด: ใส่/ถอด, ตีบวก (แสดงโอกาส + Pity + ระดับถ้าพลาด), ใส่/ถอดรูน, แยกชิ้น
   - ตอนเลือกอุปกรณ์ แสดงค่าที่จะเปลี่ยนเทียบชิ้นเดิม (เขียว/แดง)
2. **เหมือง**
   - จำนวน Pickaxe / Bomb / หิน
   - ปุ่ม "ขุด" และ "ระเบิด" (มีปุ่มใช้ทั้งหมด)
   - กระเป๋ารูน
3. **สุ่ม**
   - จำนวนเพชร
   - ปุ่มสุ่ม 1 / 10
   - ตัวนับ Pity Legendary (เช่น "อีก 34 ครั้งการันตี Legendary")
   - ตาราง rate

ไอคอนทั้งหมดสร้างตาม `docs/gemini-item-icons-prompt.md`

## 13. ลำดับการพัฒนา

1. `src/gear.ts` + ทดสอบกติกาทุกข้อ + จำลองความสมดุล
2. เซฟ (`save.ts`) + ย้ายเซฟเก่า
3. ใช้ stat ในการยิง + ระบบคริของทหาร
4. ดรอปของตอนผ่านสเตจ + แสดงในหน้าสรุปผล
5. UI แท็บสวมใส่ (กระเป๋า + รายละเอียด + ตีบวก + รูน)
6. UI แท็บเหมือง
7. UI แท็บสุ่ม
8. ใส่ไอคอนจริง + ปรับตัวเลขหลังลองเล่น
9. อัปเดต README และเลขเวอร์ชัน

## 14. เรื่องที่ยังต้องยืนยัน

1. **ชื่อสกุลเงิน** ใช้ชื่อ "เพชร" หรือไม่ ในโฟลเดอร์รูปมี `crystal.png` อยู่แล้ว ต้องดูว่าเกมใช้คำนี้ทำอะไร จะได้ไม่สับสน
2. **รูปทรงอาวุธ** ทหารแต่ละยุคใช้อาวุธต่างกัน ไอคอนอาวุธจะเป็นดาบตามที่วางไว้ หรือเปลี่ยนตามยุค
3. **ความเร็วในการหาของ** โดยเฉพาะตี +6 ที่ต้องเล่นประมาณ 116 รอบ จะใช้ตามนี้หรือเพิ่มเรทดรอป
