# CrowdAges — คู่มือสำหรับ Agent

เอกสารนี้สรุปทุกอย่างที่ต้องรู้ก่อนแก้เกม CrowdAges (เวอร์ชันล่าสุด **4.6.0**, versionCode 20)
กฎที่ห้ามละเมิดอยู่ใน [`rule.md`](rule.md) • งานที่ทำแล้ว/ค้างอยู่ใน [`task.md`](task.md) • คู่มือผู้เล่นอยู่ใน [`README.md`](README.md)

---

## 1. เกมนี้คืออะไร

เกมมือถือ Android แนว **วิ่งยิงคุมฝูงทหาร** (runner-shooter) เดินทางผ่าน 6 ยุคประวัติศาสตร์ ได้แรงบันดาลใจจากแนวเกม "Mob Era: Age Evolution" แต่ **ชื่อ กราฟิก และโค้ดเป็นของเราเองทั้งหมด**

- ไม่มีโฆษณา ไม่มีการซื้อในแอป
- Stamina ฟื้น +1 ทุก 5 นาที สูงสุด 10
- ส่งมอบเป็นไฟล์ APK (sideload)
- ข้อความในเกมเป็นภาษาไทย

## 2. เทคโนโลยี

| ส่วน | ใช้ |
|---|---|
| ภาษา | TypeScript (strict, `tsc --noEmit` ต้องผ่าน) |
| 3D | Three.js 0.187 (InstancedMesh + MeshToonMaterial ไล่แสงการ์ตูน 3 ระดับ) |
| UI | DOM overlay (`src/ui/ui.ts` + `styles.css`) ฟอนต์ Kanit |
| Bundler | Vite 8 |
| Android | Capacitor 8 (`appId: com.crowdages.game`) |
| บันทึก | localStorage (save version 4) |

โปรเจกต์อยู่ในโฟลเดอร์ `game/` ของ repo `pdf_eef` (ส่วนนอก `game/` เป็นโปรเจกต์อื่น ห้ามแตะ)

## 4. Build / Run / Test

```bash
cd game
npm install
npm run dev            # เล่นในเบราว์เซอร์ (vite --host)
npm run build          # tsc --noEmit + vite build → dist/
npx vite preview --port 4173 --strictPort   # เสิร์ฟ dist สำหรับทดสอบ

# APK (ต้องมี Android SDK; ในเซสชันนี้ SDK อยู่ใน scratchpad)
npm run build && npx cap sync android
cd android && ANDROID_HOME=<sdk> ./gradlew assembleRelease --no-daemon -q --max-workers=1
# ผลลัพธ์: android/app/build/outputs/apk/release/app-release.apk (เซ็นด้วย crowdages-sideload.keystore)
```

**Test hook** (ใช้กับ Playwright):
- `window.__game` = อินสแตนซ์ Game (อ่าน `state`, `stage`, `squad`, `targets`, `pads`, `waiters`, `save` ได้)
- `window.__steps = N` เร่งเวลาจำลอง N เท่า (0 = หยุดเวลา)
- เปลี่ยนยุค: `g.save.level = N; g.buildLevel(); g.toMenu();`
- Playwright + Chromium ติดตั้งไว้แล้ว ใช้ `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader` เพื่อให้ WebGL ทำงาน
- บอทปรับสมดุล (`campaign.cjs <eras> [maxRuns] [steps]`) ซื้ออัปเกรดระหว่างรอบแล้วนับว่ากี่รอบถึงผ่านยุค (เก็บใน scratchpad ไม่ได้ commit)

## 5. เกมเพลย์ปัจจุบัน (v4.6.0)

### 5.1 วงจร
`menu → run (สเตจ 1–3) → bonus (สเตจ 4 ทุ่งหอคอย) → won/lost → result`

- **1 ยุค = 1 รอบ = 4 สเตจ** • 6 ยุค = 1 ไทม์ไลน์ ครบแล้วเริ่มไทม์ไลน์ถัดไปที่ยากขึ้น
- ยุค: หิน → โบราณ → อัศวิน → ดินปืน → สมัยใหม่ → อนาคต
- 1 รอบใช้ Stamina 1 เล่นจนทหารหมด หรือไปถึงหอคอยแถวสุดท้าย (= ผ่านยุค ไม่ต้องยิงทุกหอ)
- ไม่มีบอส ไม่มีกรง ไม่มีกับดัก ไม่มีป้ายพลังยิง (ตัดออกใน v4.0)

### 5.2 ทหาร
- ผู้เล่นลากนิ้วซ้าย–ขวาเท่านั้น วิ่ง 5 หน่วย/วิ ยิงเอง **1.3 นัด/วิ/ตัว** ระยะ 13 กระสุน 26 หน่วย/วิ
- ดาเมจต่อนัด = พลังโจมตี × `TIER_DAMAGE[Lv]` × `FIRE_RATE_SCALE` (1/2.2 ล็อกไว้ — เปลี่ยนอัตรายิงแล้วดาเมจต่อนัดไม่เปลี่ยน)
- `TIER_DAMAGE` Lv.1–10 = 1, 1.6, 2.4, 3.5, 5, 7, 9.5, 12.5, 16, 20
- ฝูงสูงสุด **20 ตัว** ไม่นับฮีโร่ เกินแล้วไม่มีผล
- ทหาร Lv. สูงแต่งตัวเป็นทหารยุคถัดไป (`tierLook`) เสื้อเปลี่ยนสีตาม `TIER_COLORS`
- **ตายได้ 2 ทางเท่านั้น**: ชนหอคอย และโดนอาวุธที่ศัตรูปา

### 5.3 สเตจ 1–3 (ช่วงวิ่ง)
ถนนกว้าง 10, 3 เลน (x = −3.2, 0, 3.2) สเตจละ `min(7, 4 + floor(hard/3))` แถว ห่าง 22–28 หน่วย
สุ่มชนิดตามน้ำหนัก: หุ่นไล่กา 3, แท่นแคปซูล 2, ป้ายสถานะ 1.4, ศัตรู 1.2 (ศัตรูไม่ออกสเตจ 1 ยุคแรก)
ชนิดเดิมไม่ซ้ำติดกัน ยกเว้นหุ่นไล่กา • หลังแต่ละแถวมีกองเงิน 50%

**บังคับ:** สเตจ 1 แถวแรก = ป้าย แถวสอง = แท่น • ทุกสเตจมีแท่นอย่างน้อย 1 • แถวสุดท้ายของสเตจ 3 = แท่นเสมอ

| วัตถุ | ยิง | ชน/วิ่งผ่าน |
|---|---|---|
| **หุ่นไล่กา** (หน้าตาเดียวทุกยุค, แถวละ 1) | ไม่แตก ทุกนัดเติมหลอดซ้าย 1 | หุ่นหายไป ทหารไม่ตาย |
| **แท่นแคปซูล** | สะสม EXP ให้แท่น (แคปซูลไม่แตกจากกระสุน) | ชนใบใดก็ได้ → แตกทุกใบ ทหารไปยืนรอหลังเส้นสเตจถัดไป |
| **ป้ายสถานะ** (อัตรายิง/ระยะยิง, แผงไม้ 50%) | ยิงแผงไม้ให้พังก่อน แล้วค่าเพิ่มไม่จำกัด | ได้ผลจริง = ค่า × 0.1% |
| **ศัตรูชุดดำ** (2–5 ตัว) | ตายตามเลือด (~2 นัด) | ศัตรูล้ม ทหารไม่ตาย; ศัตรูปาอาวุธทุก 2–3.2 วิ โดน = ตาย 1 |
| **กองเงิน** | – | ต้องเดินชนเก็บ มูลค่า 4 + hard×2 (× รายได้) |
| **เส้นสเตจ** (สีฟ้า "สเตจ N") | – | ข้ามแล้วทหารที่รอเข้าฝูง + ข้อความ "สเตจ X/4 • ทหาร +N" |

**หลอดซ้าย (จำนวนแคปซูล):** ยิงโดนหุ่นไล่กา 1 นัด = 1 ครั้ง ต้องโดน `round(20 × 1.35^n)` ครั้ง (20, 27, 36, 49…) เต็มแล้วทุกแท่นที่ยังไม่ผ่านได้แคปซูล +1 (สูงสุด 5) • หลอดและโบนัสอยู่ตลอดรอบ ไม่รีเซ็ตตอนขึ้นสเตจ

**EXP แท่น (Level ทหาร):** ยิงแคปซูล/แท่น = EXP • Lv ถัดไปใช้ `levelHp × 1.6^(Lv−1)` • สูงสุด Lv.10 • แคปซูลเริ่ม `min(5, 1 + floor(capacityLvl/10))`

**ทหารรอ (Waiter):** ทหารจากแคปซูลวิ่ง 10 หน่วย/วิ ไปยืนเรียงจากกลางออกข้างหลังเส้น `stageD[stage+1]` แล้ว `deliverPending()` ตอนฝูงข้ามเส้น

### 5.4 สเตจ 4 (ทุ่งหอคอย)
- 10 แถว × 3 หอ ห่าง 5.5 สีไล่ ฟ้า → เขียว → ม่วง → ทอง → แดง
- เลือด = `towerDPS × min(0.85, 0.5 + 0.07×eraOrd) × 1.22^k × (0.85–1.15) × relief`
  โดย `towerDPS = min(20, 5 + 1.4×hard) × 1.3 × 1.4^eraOrd × 1.6`
- แตกแล้วได้เงิน `(3 + 0.8 hard) × 1.15^k` • 18% ของหอตั้งแต่แถว 3 มีดาว
- ชนหอ: ฝูงหยุด ทหารตาย 1 ตัวทุก 0.3 วิ จนกว่าหอตรงหน้าจะแตก

### 5.5 ความยาก
- `hard = 1 + 0.5 × (3(N−1) + s)` (N = ลำดับยุคเริ่ม 1, s = สเตจ 0–2)
- `dmgRef = (1.1^(hard−1))^0.65 × power^0.35` • `HP(k) = max(2, DPS × k × relief)`
- แผงไม้ HP(0.45), แคปซูล HP(0.55), EXP แท่น HP(0.8)
- `relief`: แพ้ติดกันลดเลือดทุกอย่าง 12%/ครั้ง สูงสุด 36%
- seed = เลขยุค → เล่นซ้ำได้ด่านเดิม
- บอท (v4.6.0) ใช้กี่รอบต่อยุค: ยุค 1 = 1, ยุค 3 = 1, ยุค 6 = 3, ยุค 8 = 4

### 5.6 เศรษฐกิจ
- **อัปเกรดในยุค (เหรียญ, รีเซ็ตทุกยุค):** รายได้ (เงิน ×(1+0.2L)), ความจุ (แคปซูล/หลอดเริ่ม), เพิ่มทหาร (เริ่ม 1+L+veteran), พลังโจมตี (×1.15^L) ราคา `(ฐาน + step×L) × (1 + 0.3×eraOrd)`
- **ค่ายฝึก (ดาว, ถาวร):** ทุนตั้งต้น (+100 เหรียญ/ระดับ, max 20), ฝึกยิง (+8%, 25), ทหารผ่านศึก (+1 ทหาร, 5), คลังเสบียง (หลอดเริ่ม +10%, 9)
- **ผ่านยุค:** เหรียญ 100×(1+0.3 eraOrd) + ที่เก็บได้ → แลกดาว 400:1, ดาว +10 (+1 +ที่เก็บ), ถ้วย 3, Stamina +5 (เกินหลอดได้) แล้วรีเซ็ตอัปเกรดในยุค เหรียญเริ่ม 100 + ทุน
- **ไม่ผ่าน:** ได้เงินที่เก็บมาเต็มจำนวน + ดาวที่เก็บ • วงล้อคูณเงินโผล่ 40% (×1.2–×3)

### 5.7 ฮีโร่
6 ตัว ปลดล็อกตามยุคที่ไปถึง (ยุค 1–6) วิ่งไปกับฝูง ใช้สกิลอัตโนมัติ อัปเลเวลด้วยถ้วย (2L+1) Level รีเซ็ตเป็น 1 ทุกยุคใหม่ ดาเมจสกิล × (1 + 0.4(L−1))
นักปรุงยาเพี้ยน (ขวดกรด) • นักชกเพลิง (หมัดไฟ คริ) • คนตัดไม้ยักษ์ (ขวานทะลุ) • นักพรตสายลม (ลม 3 สาย) • นักบินโดรน (มิสไซล์) • นักล่าสมบัติ (ปืนคู่ ได้เงิน/ดาว)
แท็บ Pets / Gears ในหน้า TEAM ยังเป็น "เร็วๆ นี้"

### 5.8 Save
`SaveData` v4 ใน localStorage (key `crowd-ages-save-v1`): `level` = เลขยุครวม, coins, stars, trophies, stamina, upgrades, meta, heroes, settings, failStreak
migration: v3 แปลงเลขด่านเป็นยุค `floor((level−1)/5)+1`, v2 ผ่านรอบ 30 ด่านเดิม
